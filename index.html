选择题3. Mass Pike是一条只在繁忙时段拥堵的收费公路。在一天的其他时间，高速公路的使用并没有___，因此有效率的收费是___。

A.排他性，更高的收费

B.排他性，零

C.消费竞争性，更高的收费

D.消费竞争性，零

答案：D

不拥堵时，一辆车使用公路不影响其他车辆的通行，没有消费竞争性，也不产生负外部性。外部性为零时无需收费纠正，故有效率的收费为零。

\(\require{physics}\)

本次是第10章节 “外部性” 的部分问题和解答。

4. 如果___，命令与控制政策就比矫正税更好。

A. 矫正税对不同行业有不同的影响

B. 一些污染者可以比其他污染者更低成本地减少污染

C. 负外部性极大，以至于最优数量为零

D. 关于减少污染的成本的知识是分散且难以得到的

答案：C

解题思路：

当负外部性极大、社会最优数量为零时，政府应直接禁止该活动（命令与控制），而不是依靠矫正税。矫正税理论上调得足够高也能压到零，但实际操作中难以精确校准；直接禁止更简单、确定。

选项 为什么不是命令与控制的优势
A. 矫正税对不同行业有不同影响 矫正税正常运作的结果，不是问题
B. 减污成本不同 恰是矫正税/许可证的优势 — 低成本多减、高成本少减，总成本最低
C. 负外部性极大，最优数量为零 ✅ 应直接禁止
D. 减污成本知识分散 恰是矫正税/许可证的优势 — 政府不需要知道每家成本，企业根据私有信息自己决策

《经济学原理》问题与应用（9）

发表于 2026/06/07 分类于 经济学原理 本文字数： 6.8k 阅读时长 ≈ 25 分钟

\(\require{physics}\)

本次是第9章节 “应用：国际贸易” 的部分问题和解答。

选择题1. 多边贸易协定的目的通常是___。

A.使各国关税水平相等，以便没有一个国家处于相对不利的情形

B.用定向关税来确保各国生产自己有比较优势的产品

C.同时降低各国关税，以减弱贸易保护主义的政治压力

D.确保关税仅用于扶持最终会有活力的幼稚产业

答案：C

多边贸易协定的目的就是在多个国家之间同时降低关税（A 不是"使各国关税相等"，B 不是"定向关税"，D 把关税局限于幼稚产业，均错）。其运作逻辑是政治平衡：若单边减税，只有进口竞争行业会组织起来反对（受益的消费者太分散）；但多国同时降税时，本国出口行业也会成为自由贸易的受益者和政治支持者，从而制衡保护主义游说压力，使减税在政治上更可行。

《经济学原理》问题与应用（8）

发表于 2026/05/30 分类于 经济学原理 本文字数： 5.5k 阅读时长 ≈ 20 分钟

\(\require{physics}\)

本次是第8章节 “应用：税收的代价” 的部分问题和解答。

选择题1. Donna经营一家旅店，且每个房间每晚收费300美元，这等于她的成本。Sam、Harry和Bill是三个潜在的顾客，分别愿意支付500美元、325美元和250美元。当政府对旅店经营者每晚租出一间客房征税50美元时，Donna把价格提高到每晚350美元。税收的无谓损失是___。

A.25美元

B.50美元

C.100美元

D.150美元

答案：A

税前 \(P=300=成本\)，Donna 利润为 \(0\)。Sam（愿付 \(500\)）和 Harry（愿付 \(325\)）购买，Bill（愿付 \(250\)）不买。

税后 \(P=350\)，Donna 税后到手 \(350-50=300\)，利润仍为 \(0\)。Sam 仍买；Harry 因 \(350>325\) 退出市场。

消失的交易是 Harry 这一笔：Harry 愿付 \(325\)，Donna 成本 \(300\)，社会净收益 \(=325-300=25\)。这笔剩余因税收无法形成，即为无谓损失。生产者剩余在 Harry 这单上本来也为 \(0\)，故无生产者剩余损失。

无谓损失 = 25 美元。

《经济学原理》问题与应用（7）

发表于 2026/05/18 分类于 经济学原理 本文字数： 5.3k 阅读时长 ≈ 19 分钟

\(\require{physics}\)

本次是第7章节 “消费者、生产者与市场效率” 的部分问题和解答。

选择题1：大于供求均衡水平的产量是无效率的，因为此时边际买者的支付意愿是___。

A.负数

B.零

C.正数但小于边际卖者的成本

D.正数并大于边际卖者的成本

答案：C

当产量 \(Q > Q^*\)（均衡产量）时，供求图中该产量对应的竖线位于均衡交点右侧。此时：

  • 边际买者的支付意愿（需求曲线高度）\(> 0\)，但仍低于均衡价格；
  • 边际卖者的成本（供给曲线高度）高于均衡价格；
  • 因此支付意愿为正，且 小于边际卖者的成本。

多生产这一单位时，买者愿意付的钱不足以覆盖卖者的成本，该单位使总剩余减少，故 \(Q > Q^*\) 的产量无效率。

《经济学原理》问题与应用（6）

发表于 2026/05/10 分类于 经济学原理 本文字数： 6.5k 阅读时长 ≈ 23 分钟

\(\require{physics}\)

本次是第6章节 “供给、需求与政府政策” 的部分问题和解答。

选择题1. 对一种物品的消费者征收每单位1美元的税收相当于___。

A.向这种物品的生产者征收每单位1美元的税收

B.对这种物品的生产者支付每单位1美元的补贴

C.使该物品的每单位价格提高了1美元的价格下限

D.使该物品的每单位价格提高了1美元的价格上限

答案：A

解析：

对消费者征税 → 需求曲线下移 1 美元 → 均衡价格（生产者到手价）下降，均衡数量减少，消费者实际支付价格 = 均衡价格 + 1 美元。

对生产者征税 → 供给曲线上移 1 美元 → 均衡价格（消费者支付价）上升，均衡数量减少，生产者实际到手价格 = 均衡价格 − 1 美元。

结论： 两种征税方式产生的均衡数量、买卖双方实际承担的价格和总税收收入完全相同。税负在买卖双方之间的分摊比例仅取决于供给和需求的价格弹性，与税收法律上向谁征收无关。

《经济学原理》问题与应用（5）

发表于 2026/04/19 分类于 经济学原理 本文字数： 6.9k 阅读时长 ≈ 25 分钟

\(\require{physics}\)

本次是第5章节 “弹性及其应用” 的部分问题和解答。

选择题1. 如果某种物品的需求___弹性___1，该物品的价格上升会引起消费者对该物品的支出总量减少

A. 收入，小于

B. 收入，大于

C. 价格，小于

D. 价格，大于

答案：D

  1. 支出总量与总收益：消费者的支出总量即卖者的总收益（\(TR = P \times Q\)）。
  2. 价格弹性与总收益的关系：
    • 当需求富有弹性（弹性 \(> 1\)）时，价格上升引起的数量减少比例大于价格上升比例，导致总收益减少。
    • 当需求缺乏弹性（弹性 \(< 1\)）时，价格上升引起的数量减少比例小于价格上升比例，导致总收益增加。
  3. 结论：题目要求价格上升导致支出减少，说明需求富有弹性（价格弹性大于 1）。

《经济学原理》问题与应用（4）

\(\require{physics}\)

本次是第4章节 “供给与需求的市场力量” 的部分问题和解答。

什么是竞争市场？简单描述一种不是完全竞争的市场。

竞争市场是指有大量买者和卖者、任何单个参与者都不能显著影响市场价格的市场，市场价格主要由供求共同决定。

一种不是完全竞争的市场是电信市场。无论在中国还是美国，基础电信运营商数量都比较少，市场由少数大型运营商主导，进入门槛高（牌照、基础设施、频谱资源等），单个企业对价格和服务有一定影响力，因此它更接近寡头竞争，而不是完全竞争市场。

除了这个外，还有 民航、操作系统、搜索引擎、社交平台、自来水/电力、高铁客运等公共事业等。

Tip

这类市场通常具有高固定成本和高进入壁垒，并伴随显著规模经济，因此一般不会呈现完全竞争结构，而更可能表现为寡头或自然垄断。 寡头是少数企业主导的市场结构，自然垄断是由高固定成本和显著规模经济导致的一家供给更有效的市场结构；前者不一定是企业主动垄断，后者主要由行业技术与成本条件自然形成，但两者都可能需要反垄断或价格监管。
