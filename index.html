《经济学原理》问题与应用（7）

发表于 2026/05/18 分类于 经济学原理 本文字数： 5.3k 阅读时长 ≈ 19 分钟

\(\require{physics}\)

本次是第7章节 “消费者、生产者与市场效率” 的部分问题和解答。

选择题1：大于供求均衡水平的产量是无效率的，因为此时边际买者的支付意愿是___。

A.负数

B.零

C.正数但小于边际卖者的成本

D.正数并大于边际卖者的成本

答案：C

当产量 \(Q > Q^*\)（均衡产量）时，供求图中该产量对应的竖线位于均衡交点右侧。此时：

  • 边际买者的支付意愿（需求曲线高度）\(> 0\)，但仍低于均衡价格；
  • 边际卖者的成本（供给曲线高度）高于均衡价格；
  • 因此支付意愿为正，且 小于边际卖者的成本。

多生产这一单位时，买者愿意付的钱不足以覆盖卖者的成本，该单位使总剩余减少，故 \(Q > Q^*\) 的产量无效率。

《经济学原理》问题与应用（6）

发表于 2026/05/10 分类于 经济学原理 本文字数： 6.5k 阅读时长 ≈ 23 分钟

\(\require{physics}\)

本次是第5章节 “供给、需求与政府政策” 的部分问题和解答。

选择题1. 对一种物品的消费者征收每单位1美元的税收相当于___。

A.向这种物品的生产者征收每单位1美元的税收

B.对这种物品的生产者支付每单位1美元的补贴

C.使该物品的每单位价格提高了1美元的价格下限

D.使该物品的每单位价格提高了1美元的价格上限

答案：A

解析：

对消费者征税 → 需求曲线下移 1 美元 → 均衡价格（生产者到手价）下降，均衡数量减少，消费者实际支付价格 = 均衡价格 + 1 美元。

对生产者征税 → 供给曲线上移 1 美元 → 均衡价格（消费者支付价）上升，均衡数量减少，生产者实际到手价格 = 均衡价格 − 1 美元。

结论： 两种征税方式产生的均衡数量、买卖双方实际承担的价格和总税收收入完全相同。税负在买卖双方之间的分摊比例仅取决于供给和需求的价格弹性，与税收法律上向谁征收无关。

《经济学原理》问题与应用（5）

发表于 2026/04/19 分类于 经济学原理 本文字数： 6.9k 阅读时长 ≈ 25 分钟

\(\require{physics}\)

本次是第5章节 “弹性及其应用” 的部分问题和解答。

选择题1. 如果某种物品的需求___弹性___1，该物品的价格上升会引起消费者对该物品的支出总量减少

A. 收入，小于

B. 收入，大于

C. 价格，小于

D. 价格，大于

答案：D

  1. 支出总量与总收益：消费者的支出总量即卖者的总收益（\(TR = P \times Q\)）。
  2. 价格弹性与总收益的关系：
    • 当需求富有弹性（弹性 \(> 1\)）时，价格上升引起的数量减少比例大于价格上升比例，导致总收益减少。
    • 当需求缺乏弹性（弹性 \(< 1\)）时，价格上升引起的数量减少比例小于价格上升比例，导致总收益增加。
  3. 结论：题目要求价格上升导致支出减少，说明需求富有弹性（价格弹性大于 1）。

《经济学原理》问题与应用（4）

发表于 2026/04/13 分类于 经济学原理 本文字数： 5.5k 阅读时长 ≈ 20 分钟

\(\require{physics}\)

本次是第4章节 “供给与需求的市场力量” 的部分问题和解答。

什么是竞争市场？简单描述一种不是完全竞争的市场。

竞争市场是指有大量买者和卖者、任何单个参与者都不能显著影响市场价格的市场，市场价格主要由供求共同决定。

一种不是完全竞争的市场是电信市场。无论在中国还是美国，基础电信运营商数量都比较少，市场由少数大型运营商主导，进入门槛高（牌照、基础设施、频谱资源等），单个企业对价格和服务有一定影响力，因此它更接近寡头竞争，而不是完全竞争市场。

除了这个外，还有 民航、操作系统、搜索引擎、社交平台、自来水/电力、高铁客运等公共事业等。

Tip

这类市场通常具有高固定成本和高进入壁垒，并伴随显著规模经济，因此一般不会呈现完全竞争结构，而更可能表现为寡头或自然垄断。 寡头是少数企业主导的市场结构，自然垄断是由高固定成本和显著规模经济导致的一家供给更有效的市场结构；前者不一定是企业主动垄断，后者主要由行业技术与成本条件自然形成，但两者都可能需要反垄断或价格监管。

\(\require{physics}\)

Profiling V.S. Tracing

先给结论：Profile 负责回答“慢在哪里”，Trace 负责回答“为什么会慢”。

参考 Tracing 101，两者可以这样区分：

  • Profiling（采样/热点分析）

    • 典型工具：VTune、Linux perf、pprof
    • 结果：热点函数、调用栈、CPU 占比、内存热点
    • 优势：开销相对小，便于长期趋势对比
    • 局限：上下文较弱，跨线程因果关系不直观

  • Tracing（时序/因果分析）

    • 典型工具：Perfetto
    • 结果：时间线、线程切换、跨线程流转、阶段耗时、Counter 曲线
    • 优势：上下文完整，适合分析卡顿、抖动、排队、阻塞
    • 局限：数据量大，采集策略需要设计
